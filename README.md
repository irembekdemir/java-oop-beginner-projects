# Student Grade Calculator (Java)

A simple Java program to calculate a student's weighted average and letter grade based on midterm and final exam scores.

## Features

- Input student's name, midterm score, and final exam score (system args)
- Calculate numeric average
- Display letter grade (A+, A, B+, B, C, D, F)
- Midterm contributes 40% and final exam 60% to the total score (weighted)
- The program calculates average and determines letter grade using a switch-case structure
- Simple console-based Java application

## Usage
Run the program from the terminal with 3 arguments:
```bash
java Student <name> <midterm> <final>
```
